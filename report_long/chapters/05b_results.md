## 網路成癮、FOMO 與睡眠（Q4）

第 5.3 節顯示，控制上床時間後深夜螢幕沒有可偵測的額外關聯；但網路成癮量表測的不是「用多久」，而是「能不能控制地用」（如「無法上網就坐立不安」、熬夜上網）。本節追問：網路成癮（失控使用）與晚睡誰走在前面？網路成癮與錯失恐懼（FOMO）和一年後憂鬱的關聯，有多少經由晚睡？若經由睡眠的部分很小，失控使用就需要在作息之外另外處理。樣本以課堂 A 卷學生（89 校）為主，方法見第 4.5、4.6 節。

### 成癮與晚睡互相預測

在兩波交叉延宕模型（CLPM；圖{fig:clpm_bedtime}、表{tab:clpm_paths}）中，網路成癮與上床時間互相預測：國七網路成癮每高 1 SD，國八上床時間（相對於依其國七上床時間所預期者）較晚，β = 0.049，95% CI [0.016, 0.083]，q = .013；國七上床時間較晚者，國八網路成癮也較高，β = 0.072 [0.041, 0.104]，q < .001。兩者帶號差為 −0.023 [−0.072, 0.026]，p = .370，沒有主導方向，較符合「互相預測」而非單向的描述。以睡眠時數取代上床時間，型態相同（成癮 → 睡眠時數 β = −0.063，q = .002；睡眠時數 → 成癮 β = −0.054，q = .012）。須注意網路成癮量表含「熬夜上網」題，兩個構念在題意上部分重疊，互相預測的強度可能因此略為偏高（見第 6.5 節）。

成癮與憂鬱的關係則較偏向單一方向。國七網路成癮 → 國八憂鬱 β = 0.084 [0.044, 0.122]，q < .001，是 CLPM 中最大的交叉延宕路徑；反向的國七憂鬱 → 國八成癮 β = 0.034 [−0.002, 0.071]，q = .130。兩者差 +0.050 [−0.009, 0.108]，p = .101：順向點估計較大，但差異未達顯著，不能排除小幅的反向路徑。若把兩段一年的路徑相乘（跨波鏈，需假設路徑跨年穩定），「成癮 → 上床時間 → 憂鬱」為 0.0032 [0.0009, 0.0062]，p = .003，反向鏈「憂鬱 → 上床時間 → 成癮」只有 0.0003 [−0.0023, 0.0029]，p = .823。「成癮在前、晚睡居中、憂鬱在後」的時間順序與資料相符，但這條鏈的量遠小於成癮 → 憂鬱的交叉路徑本身（0.084）。

### 半縱貫中介：經由睡眠的部分很小

半縱貫中介（設定見第 4.6 節）以 a 路徑（國七暴露預測國八上床時間，控制國七上床時間、國七憂鬱與共變項，即一年間上床時間往後移了多少）乘上 b 路徑（國八上床時間與國八憂鬱的關聯），得到經由睡眠的間接關聯；b 路徑取國八同期測量者為同期版（上界），以國七上床時間預測國八憂鬱者為時序版（下界）。路徑見圖{fig:mediation_bedtime}，完整數字見表{tab:mediation}。

**網路成癮。** a 路徑 β = 0.049（p = .009）：國七網路成癮每高 1 SD（0.67 分，1–4 分量尺），國八上床時間晚 3.3 分鐘 [1.0, 5.6]。b 路徑 β = 0.205（p < .001）：國八上床時間每延後 1 小時，**同期**的國八憂鬱高 1.56 分（0–44 分量尺）；這是同一時間點的關聯，不是一年後的變化（一年後的原始單位估計為每延後 1 小時 +0.60 分，見第 5.2 節）。總關聯 c β = 0.083（約 +0.71 分），直接關聯 c′ β = 0.073；間接關聯 β = 0.0100 [0.0028, 0.0182]，q = .006，只相當於 +0.085 分 [0.024, 0.153]；時序版更小，β = 0.0034 [0.0009, 0.0066]，q = .006。中介比例（a × b ÷ c）因此介於 4% [1%, 10%]（時序版）與 12% [3%, 27%]（同期版）之間；以睡眠時數為中介亦相近（6% [1%, 16%] 至 15% [6%, 35%]）。全樣本版本的比例較大（同期版 23% [16%, 33%]），但 B 卷學校沒有國七上床時間、無法控制基線作息，a 路徑偏高（β = 0.123），屬高估，不作主結果。

**熬夜（23 點後仍醒著）。** 相對於 23 點後已入睡者，國七晚間日誌 23 點後仍醒著的學生，一年後上床時間比依其國七上床時間所預期者再晚 13.4 分鐘 [8.1, 18.5]，經由上床時間的間接關聯 β = 0.0174 [0.0094, 0.0256]，q = .002（約 +0.35 分 [0.20, 0.52]）；但控制國七上床時間後，熬夜與國八憂鬱的總關聯不顯著（c β = 0.029），因此不計中介比例。依日誌三分類拆開，以螢幕為主者的間接關聯為 0.0186，只做非螢幕活動者為 0.0078 [0.0006, 0.0152]；兩者差 0.0103 [0.0007, 0.0207]（q = .049）在主樣本中勉強排除 0，但納入課後自願補填者（0.0076 [−0.0020, 0.0177]）或排除國七高憂鬱症狀者（0.0091 [−0.0013, 0.0208]）時 CI 皆含 0。這與第 5.3 節日誌對照（表{tab:diary_specificity}）的結論一致：螢幕組點估計較大，但與非螢幕組的差異證據薄弱。

**FOMO。** 國七 FOMO 與國八上床時間幾乎無關（a β = 0.014，p = .409；每 SD 只晚 0.9 分鐘 [−1.1, 3.2]），間接關聯 β = 0.0029 [−0.0033, 0.0100]，q = .389；以睡眠時數為中介時 q = .058，FDR 校正後亦不顯著。FOMO 與國八憂鬱的關聯主要落在直接路徑（c′ β = 0.065，p < .001）。

### 預警分析中的關聯與 E 值

第 5.6 節預警分析的關聯推論以不同的結果定義得到相同訊息。控制國七 CESD 與性別（P1）時，國七網路成癮每高 1 SD，新發生憂鬱或自傷意念風險的 OR = 1.25 [1.16, 1.34]（n = 7,005）；再控制睡眠品質、自尊、生活滿意、WHO-5 與偏好網路勝過現實（P2；限 A 卷作答者，n = 3,468）後仍為 1.13 [1.02, 1.25]，p = .015；未調整發生率由成癮平均分 < 1.5 者的 15.1% 逐級升到 ≥ 3 者的 33.4%。FOMO 則由 P1 的 OR = 1.16 [1.08, 1.26] 變為 P2 的 1.04 [0.95, 1.14]，p = .392，其關聯被網路成癮、自尊等因子吸收。

E 值的計算與解讀同第 5.2.2 節。以國八高憂鬱症狀（不含睡眠題的換算門檻）為結果、控制國七憂鬱與國七上床時間時，國七網路成癮 OR = 1.26 [1.10, 1.43]，保守的 √OR 轉換 E = 1.49（CI 界 1.28；依罕見結果近似則為 1.82）；FOMO 的 E = 1.46（CI 界 1.27）。同一模型中除國七憂鬱外關聯最強的已測共變項是數位發展潛力區（√OR 1.29）；只要有一個獨立於國七憂鬱、強度相當的未測混淆，CI 就可能涵蓋 1，因此穩健性屬偏弱至中等。

綜合第 5.3 節與本節：網路成癮與晚睡互相預測，但成癮與一年後憂鬱的關聯只有約 4%–12% 經由晚睡，絕大部分落在不經睡眠的直接路徑；FOMO 則幾乎不經由睡眠。也就是說，控制晚睡後消失的是「深夜用螢幕」的額外訊號，而不是失控使用本身；就寢時間與失控使用是兩個需要同時處理的對象（教育意涵見第 6.4 節）。

規範限制（規定上網時段、限制上網時長）是唯一與作息有清楚關聯的數位教養：每高 1 SD，國八上床時間 β = −0.133 [−0.164, −0.102]，約早 9 分鐘；睡眠時數 β = +0.124 [0.095, 0.154]。但它與網路成癮（β = −0.005，q = .738）、憂鬱（β = −0.006，q = .736）都沒有關聯。衝突責罵（因上網責罵、因網購起衝突）正好相反：與上床時間無關，卻伴隨較高的網路成癮（β = +0.172 [0.139, 0.204]）與憂鬱（β = +0.110 [0.076, 0.144]），再控制國七同一結果後仍為 +0.146 與 +0.087。擔憂叮嚀、監看與鼓勵上網也都與較多成癮或憂鬱同時存在；這些正相關可能反映家長對孩子既有狀況的回應，也可能反映教養與孩子日後狀況的關聯，同期資料無法區分，方向留待交叉延宕檢查。陪伴引導只控制共變項時，與較早睡、較少成癮和較少憂鬱都相關（β = −0.073、−0.063、−0.065），加入一般親子關係後全部消失，與憂鬱甚至略為正相關（β = +0.048 [0.020, 0.076]）；較合理的解讀是其好處已被一般親子關係涵蓋，正係數可能是家長對有狀況孩子的反應性投入，不宜解讀為陪伴有害。

與憂鬱關聯最強的是一般親子關係，而非任何數位教養：敵意／冷漠 β = +0.250 [0.220, 0.280]、家庭凝聚 β = −0.143 [−0.176, −0.110]；敵意／冷漠也伴隨較多網路成癮（+0.167）。以同一樣本逐步加入預測變項，國八憂鬱的 R² 由只有共變項的 0.037，加入一般親子三構面後升為 0.142，再加入全部六種數位教養只到 0.159（ΔR² = 0.018）；上床時間與睡眠時數的數位教養增量為 0.024 與 0.021，網路成癮則最大（0.046）。

### 規則與早睡：一年前就已存在

若規範限制走在早睡之前，控制孩子一年前的作息後關聯應仍存在，而且國八規則與國八作息的關聯應強於它與國七作息的關聯。在有國七作息題的 A 卷學生中再控制國七同一作息，上床時間的係數縮為 β = −0.060 [−0.093, −0.026]（q = .001，n = 3,923），睡眠時數為 +0.056（q = .004）；但教養仍是國八測量，這不是前瞻設計。同一設定下，全樣本再控制國七網路成癮後，規範限制與國八網路成癮反而呈小幅正相關（β = +0.033 [0.008, 0.058]，q = .021，n = 8,037），可能是同一年內家長在孩子成癮升高時加立規則；但交叉延宕中國七成癮較高者一年後規範較少（第 5.5.3 節），方向無法確定。國七 B 卷的規範限制可預測國八上床時間（β = −0.091 [−0.124, −0.057]，n = 4,064），但 B 卷沒有國七作息題，無法控制基線。

關鍵的檢查是時序負對照（第 4.8 節；Lipsitch et al., 2010）：國八教養不可能回頭改變一年前的國七作息，因此若國八教養與國七作息的關聯和它與國八作息的關聯一樣強，就提示關聯來自穩定的家庭差異，而非教養本身。在同一批 A 卷學生（n = 3,923）中，國八規範限制與一年前國七上床時間的 β = −0.130 [−0.171, −0.090]，與同期國八上床時間的 β = −0.130 [−0.175, −0.084]，一樣強；睡眠時數亦然（+0.121 vs +0.123）。監看與國七上床時間的關聯（−0.058 [−0.095, −0.020]）甚至強於同期（−0.013）；六種數位教養的完整對照見附錄 B 表{tab:negctrl}。因此「有規範限制的家庭孩子較早睡」在一年前就已存在，較可能反映家庭間的穩定差異，可能是早已實行的規則，也可能是與規則、作息皆相關的家庭特質；不能據此推論家長立規則之後孩子會早睡。同時作答 A、B 卷的小樣本（每人皆有一卷為課後自願補填、非隨機，n = 431，140 校）可同時控制兩種基線，但兩種控制的差為 +0.004 [−0.056, 0.076]，樣本太小，無法裁決。

規則與成癮、憂鬱的「好處」只在六構面互相控制時出現（成癮 β = −0.142、憂鬱 β = −0.107），且主要來自控制衝突責罵。加權相關分解顯示 r(規則, 衝突) = .49，而 r(規則, 成癮) 只有 .011；控制衝突後規範限制的係數 −0.121 幾乎全部來自「衝突路徑」項（−0.136）。若衝突責罵是規則與孩子問題上網的共同結果，以它為條件就會在規則與成癮之間製造虛假的負相關（Elwert & Winship, 2014）；本研究因此不宣稱規則與較少的成癮或憂鬱有關。同樣以衝突責罵為條件的規則 × 衝突交互作用（設定（h），僅供參考）只在網路成癮上顯著（β = −0.070 [−0.096, −0.044]，q < .001）：規範限制的斜率在衝突低（−1 SD）時為 −0.052、高（+1 SD）時為 −0.192；上床時間、睡眠時數與憂鬱皆不顯著（q ≥ .82）。把鼓勵上網併入陪伴引導的五構面互相控制版本（設定（i））與六構面版幾乎相同（規範限制對上床時間 −0.195、成癮 −0.150、憂鬱 −0.106）。相對地，規範限制與上床時間的關聯不論調整集合為何都穩定，從只控共變項的 −0.124 到全部互相控制的 −0.195（附錄 B 圖{fig:restrict_adjustment}）。

### 方向：親→子還是子→親

交叉延宕同時估計「親→子」（國七教養預測國八孩子狀況，控制國七孩子狀況）與「子→親」（國七孩子狀況預測國八教養，控制國七教養）兩個方向，並以堆疊方程式的學校叢集穩健 Wald 檢定比較兩方向係數。資料為國七 B 卷學生，每組模型只含一種數位教養與一個孩子結果（圖{fig:parenting_crosslag}）。

:::figure id=fig:parenting_crosslag path=figures/fig_parenting_crosslag.png width=16 | 國七 → 國八交叉延宕（B 卷，單一構面模型）：國七較憂鬱或較成癮的孩子，一年後家長的規範限制較少。藍＝親→子（國七教養 → 國八孩子，控制國七孩子）；橘＝子→親（國七孩子 → 國八教養，控制國七教養）；每組模型只含一種數位教養與一個孩子結果，控制性別、家庭經濟、父母婚姻同住與數位發展分區；n = 4,072–4,203；實心＝BH-FDR q < .05（24 條路徑）、空心＝q ≥ .05；誤差線為 95% CI；右側為兩方向係數差異的堆疊方程式 Wald 檢定 p 值（黑字＝12 對差異校正後 q < .05）；兩波無法分離家庭間穩定差異與家庭內變化。資料：TIGPS D00262／D00268，HOUWGT 加權。

最清楚的訊號是子→親：國七憂鬱症狀較高的孩子，一年後家長的規範限制較少（β = −0.036 [−0.063, −0.010]，q = .028，n = 4,141），陪伴引導也較少（β = −0.039 [−0.065, −0.014]，q = .022）；國七網路成癮較高者，一年後規範限制同樣較少（β = −0.039 [−0.065, −0.013]，q = .022）。反之，國七規範限制不預測國八憂鬱（β = +0.018，q = .407；再控制國七一般親子關係後為 +0.011，p = .408），規則與憂鬱兩方向的係數差 +0.054 [0.020, 0.088]，p = .002，q = .022，以子→親為主。資料較像「較憂鬱或較成癮的孩子，家長後來管得較少」，而非「規則少的孩子後來較憂鬱」；這可能是家長退縮，也可能是孩子抗拒，兩波資料無法區分。

衝突責罵的前瞻證據較弱：國七衝突責罵預測國八憂鬱（β = +0.061 [0.025, 0.096]，q = .019）與網路成癮（β = +0.046 [0.015, 0.077]，q = .022），但兩方向的差異不顯著（憂鬱 p = .134、成癮 p = .530），再控制國七一般親子關係後 q 變為 .139 與 .156。因此衝突責罵與成癮、憂鬱的同期關聯明確，但前瞻證據弱、方向無法確定。國七擔憂叮嚀 → 國八網路成癮（β = +0.041 [0.013, 0.070]，q = .023）在控制國七一般親子後仍為 +0.037（q = .046），是成癮與憂鬱結果中唯一如此的數位教養路徑，但兩方向差在 FDR 校正後未達顯著（q = .096），家長的擔憂也可能反映孩子尚未顯現在量表上的早期跡象。

### 調節分析：沒有教養構面減弱成癮與憂鬱的關聯

調節分析檢驗「在某種教養較多的家庭中，網路成癮與憂鬱的關聯是否較弱」，以「成癮 × 教養」交互作用項表示，負值代表關聯被減弱。本研究在同期、半前瞻（國七成癮 × 國八教養）與國七前瞻三種設定下，連同上床時間 × 教養共檢驗 28 項，並以 BH-FDR 校正。結果：沒有任何教養構面（包括溫暖支持）減弱成癮與憂鬱的關聯，達顯著者皆為「放大」。國八網路成癮 × 擔憂叮嚀的交互作用項 β = +0.059 [0.033, 0.085]，q < .001（n = 7,998）：成癮與憂鬱的標準化斜率在擔憂叮嚀低（−1 SD）時為 0.168，高（+1 SD）時為 0.286。Johnson–Neyman 區間用來找出調節變項在哪些數值範圍內斜率顯著（Hayes & Matthes, 2009）；Johnson–Neyman 分析顯示，斜率在擔憂叮嚀的整個觀察範圍內都顯著（+0.102 至 +0.300）；圖{fig:interaction} 並列各構面低、高水準下的斜率與全部 28 個交互作用項。成癮 × 監看亦同（β = +0.066 [0.036, 0.096]，q < .001）。兩種前瞻設定的 14 項全不顯著（|β| ≤ 0.024，最小 q = .416）；放大只出現在同期資料中，可能只是反映孩子同時出現成癮與憂鬱時，家長較常擔心、查看。

:::figure id=fig:interaction path=figures/fig_interaction.png width=16 | 沒有任何教養構面減弱成癮與憂鬱的關聯，達顯著的交互作用皆為放大。(a) 國八同期：網路成癮與國八憂鬱（不含睡眠題）的標準化簡單斜率，分別在各構面低（−1 SD）與高（+1 SD）時估計，右側為該交互作用項的 BH-FDR q；(b) 同期、半前瞻與國七前瞻（B 卷）四組共 28 個交互作用項（負值＝關聯被減弱），實心＝q < .05。皆控制一般親子三構面與共變項；95% CI 以學校叢集 SE 計算；n = 4,099–8,087。資料：TIGPS D00262／D00268，HOUWGT 加權。

預警分析的關聯推論（國七教養 → 國八新發生憂鬱或自傷意念風險，控制國七 CESD 與性別；數位教養、溫暖與敵意取自國七 B 卷）呈現同樣的圖像。每 SD 的 OR：敵意／冷漠 1.32 [1.23, 1.42]、溫暖支持 0.76 [0.71, 0.83]、衝突責罵 1.16 [1.08, 1.25]、家庭凝聚 0.83 [0.78, 0.89]，皆 q < .001；規範限制 1.07 [0.99, 1.14]（q = .11）與監看 1.03 [0.95, 1.11]（q = .55）未達顯著，但 CI 仍容許小幅關聯。與孩子一年後狀況關聯較強的，是親子關係的品質與衝突，而不是管控的多寡。

## 提前一年預警（Q6）

本節回答實務問題：只用國七就有的資料，能否提早一年把較可能出現狀況的學生排在關懷名單的前面？預警的目的是排序而非解釋，模型只作為排定關懷優先順序的參考（方法見第 4.9 節；報告方式參照 TRIPOD，Collins et al., 2015）。

### 樣本與目標盛行率

預警對象是國七 CESD < 16、國八結果可判定的 7,032 名學生（178 校）。主目標「新發生憂鬱或自傷意念風險」定義為國八 CESD ≥ 16 或近 1–2 週有自傷／死亡意念，加權盛行率 21.4% [20.0%, 23.0%]（事件 1,473 人）。這個盛行率相當程度來自寬鬆的自傷指標：新發生個案中有 781 人（加權 53.2%）國八 CESD < 16、只因自傷題入列，也有 390 人（加權 26.0%）只有單一題、且為最低頻率。因此另設三個目標檢查結論是否依賴定義：共同主要目標「新發生憂鬱症狀」（只看 CESD ≥ 16）10.0% [9.1%, 10.9%]（事件 692）；嚴格自傷門檻（CESD ≥ 16，或任一自傷題 ≥ 3 天，或兩題皆有）15.8% [14.4%, 17.4%]；不排除國七高憂鬱症狀者的全樣本國八風險 26.5% [25.1%, 27.9%]（n = 8,228）。由於國七未測自傷／死亡意念，「新發生」只表示國七未達憂鬱門檻，不保證自傷／死亡意念是新出現的。

### 10 題簡短篩檢

83 個特徵在學校現場難以施測，因此從 61 個全體共同題中以前進逐步法選出 10 題；選題在每個外折內各自進行（第 4.9 節），評估用的學生從未參與選題（圖{fig:screener}）。以全樣本選出的 10 題依序為：滿意自己、覺得悲傷、無法上網就坐立不安、總是感到疲憊、覺得很寂寞、曾遭實體霸凌、女生、自評健康、睡眠情況不好、學校生活滿意；其中 4 題取自 CESD、1 題取自網路成癮量表。選題穩定度不一：滿意自己、覺得悲傷、覺得很寂寞、曾遭實體霸凌、女生、睡眠情況不好 6 題在 5 個外折中都入選，自評健康與學校生活滿意只入選 1 折；清單末端可以互換，實際使用前宜以當地資料重新驗證。題數–AUC 呈邊際遞減：1 題 0.625、3 題 0.677、5 題 0.690、10 題 0.706 [0.689, 0.724]；10 題比只用國七 CESD 高 +0.036 [0.022, 0.050]，比全特徵 HGB 低 0.013 [0.005, 0.022]（p = .008）。

:::figure id=fig:screener path=figures/fig_screener.png width=16 | 10 題簡短篩檢的 AUC 接近全特徵模型。(a) 五種模型的 AUC（95% CI）；(b) 題數–AUC，每個外折內獨立選題後評估（無選題洩漏），陰影為 95% CI，虛線為 HGB 全特徵、點線為只用國七 CESD；(c) 最終 10 題（全樣本選題順序）的每 SD 勝算比，括號為 5 個外折中的入選次數。新發生世代 n = 7,032；候選題 61 題皆為全體共同題。資料：TIGPS D00262／D00268，HOUWGT 加權。

哪些題組值得加在 10 題之後？在 A 卷作答者中（n = 3,588），10 題的 AUC 為 0.698；加入「上床時間＋FOMO＋23 點後以螢幕為主」後 ΔAUC = +0.008 [0.002, 0.013]，p = .010，約補回 HGB 與 10 題差距（0.013）的 56%；只加晚睡三項（上床時間、23 點後以螢幕為主、午夜仍醒著）為 +0.006 [0.001, 0.012]，p = .024；只加 FOMO 為 +0.001，p = .382。在 B 卷作答者中（n = 3,921），加入家長溫暖／敵意與四種數位教養只有 +0.004 [−0.001, 0.009]，p = .106。作息題對簡短篩檢有小而可偵測的增益，FOMO 與教養題則沒有。

### 模型在看什麼：SHAP 與晚睡特徵

SHAP 值的平均絕對值（平均 |SHAP|）越大，表示模型越依賴該特徵（計算方式見第 4.9 節；Lundberg et al., 2020），A、B 卷題目的排名依有作答者計算，以免重要性被稀釋。HGB 最終模型的前五名為國七憂鬱症狀、自尊、女生、生活滿意度與偏好網路勝過現實，家長敵意／冷漠第 6、網路成癮第 7（圖{fig:shap}(a)）。領域組合 SHAP 以國七心理健康 0.49 遙遙領先，其次為網路使用 0.23、家庭與教養 0.15、個人特質與背景 0.14、學校與同儕 0.13，睡眠與夜間作息最小（0.09；圖{fig:shap}(b)）；移除國七心理健康的 6 個特徵後，HGB 的 AUC 由 0.720 變為 0.689（ΔAUC = +0.030 [0.016, 0.044]），是所有領域中下降最多者（各領域見附錄 B 表{tab:dropdomain}）。SHAP 的方向也不可當作實質關聯方向：數位素養（第 10 名）與好友支持（第 11 名）的 SHAP 隨作答值上升（ρ = +0.75、+0.84），控制國七 CESD 與性別的調整 OR 卻為 0.97 與 0.96 且不顯著；晚間螢幕時段數的 SHAP 方向為負（ρ = −0.78），調整 OR 卻是 1.15。

:::figure id=fig:shap path=figures/fig_shap.png width=16 | 國七心理健康是模型最依賴的資訊，睡眠與夜間作息領域的組合 SHAP 最小。(a) HGB 最終模型前 15 名特徵的平均 |SHAP|（A／B 卷題只計有作答者）；顏色為作答值與 SHAP 值的等級相關方向（紅＝作答值越高、模型預測風險越高；藍＝相反；灰＝|ρ| < .3）；(b) 六個領域的平均 |組合 SHAP|（個人特質與背景不含「填 A 卷」「填 B 卷」兩個題本指標，計 11 個特徵）。SHAP 為模型內的條件歸因，不代表因果，也不代表實質關聯方向；相關特徵之間會分攤功勞。新發生世代 n = 7,032；TreeExplainer 計算。資料：TIGPS D00262／D00268；模型以 HOUWGT 加權訓練。

晚睡特徵最能說明「預測力」與「關聯」的差別（圖{fig:night_screen_pred}）。只控制國七 CESD 與性別時，國七「23 點後以螢幕為主」的 OR = 1.77 [1.33, 2.34]，「午夜仍醒著」的 OR = 1.74 [1.29, 2.35]，兩者幾乎相同；再控制網路成癮、睡眠品質、自尊等（P2）後仍為 1.50 [1.10, 2.05]（p = .011）與 1.44 [1.05, 1.97]（p = .024）。「有沒有用螢幕」與「是不是醒著」的 OR 幾乎一樣，支持訊號跟著「晚」走，不能當作螢幕特有關聯的證據。然而在 83 個特徵的完整模型中，從 HGB 移除整組 8 個晚睡與深夜螢幕特徵，AUC 由 0.723 變為 0.725（ΔAUC = −0.002 [−0.006, 0.002]，p = .296，A 卷 n = 3,588），「23 點後以螢幕為主」的 SHAP 排名也只有第 74／83。這不表示晚睡不重要：作息特徵彼此高度共線（上床時間與睡眠時數 r = −.87），其資訊可能已由相關特徵涵蓋。同一共線下，單一特徵的部分依賴也不可靠：全特徵 HGB 中，上床時間由 21:00 到 02:00 的預測風險只從 21.6% 升到 23.0%，拿掉共線的作息特徵後則為 21.2% 到 24.7%。判斷晚睡的角色應以多變項 OR 與第 5.2、5.3 節的縱貫分析為準，而不是 SHAP 排名或完整模型中的 ΔAUC。以 P1 逐一檢驗的 81 個國七因子中，51 個在 FDR 校正後 q < .05，完整清單見附錄 B 表{tab:adj_or}。

### 公平性與門檻政策

模型在各群體的排序能力相近：AUC 女生 0.722 [0.702, 0.742]、男生 0.697 [0.675, 0.723]，數位發展分區介於 0.707 與 0.749 之間（萌動區 n = 296，CI 很寬）；分性別的校準也尚可，觀察／期望比（O/E）女生 1.05、男生 0.96（圖{fig:fairness}）。但「用哪一條門檻」決定了誰會被找到。表{tab:thresholds} 上半顯示，標記比例越高，敏感度越高、PPV 越低：前 5% 的敏感度只有 13.2%、PPV 56.2%，前 30% 則為 54.8%、39.1%。在全樣本統一的前 15% 門檻下，女生被標記 21.9%、敏感度 41.6%，男生只被標記 8.6%、敏感度 19.8%；這主要反映基礎率不同（盛行率女生 25.9%、男生 17.3%），而非模型系統性低估男生的風險。

整體來看，穩健的部分包括：（1）晚睡走在憂鬱之前的方向，納入補填者時交叉係數不變（0.065 → 0.065），改用睡眠時數也方向一致（雖然較弱，p = .085）；（2）國七上床時間與一年後憂鬱的關聯，在多變項控制、去除 CESD 睡眠題、限主卷作答者與不同樣本設定下都存在；（3）網路成癮與晚睡互相預測、成癮經由晚睡的比例很小，在多數設定下維持；（4）晚間類型的結果在排除可疑作答、納入補填者或改用 k = 7 時都維持；（5）規範限制與上床時間的關聯不隨調整集合改變；（6）不論目標如何定義，HGB 都沒有勝過邏輯斯迴歸（替代目標下隨機森林與邏輯斯迴歸的點估計差 ≤ 0.008，未另行檢定）。

脆弱的部分則包括：（1）深夜「螢幕特有」的差異，加控起床時間後由 10.1 分鐘縮為 3.4 分鐘，納入補填者或排除國七高憂鬱症狀者時，間接關聯之差的 CI 皆含 0；（2）成癮 → 晚睡 → 憂鬱的間接關聯，在同時納入補填者並排除國七高憂鬱症狀者時 CI 觸及 0，屬邊緣穩健；（3）熬夜「總關聯不顯著」在排除國七高憂鬱症狀者後轉為顯著，不宜強調；（4）平日休閒上網時數在全模型中的 p 值隨設定在 .024–.088 之間擺動；（5）數位教養構面在半樣本與國七同義題中配適仍不佳；（6）主要關聯的保守 E 值只有 1.44–1.49。簡言之，關於「晚睡」的方向與關聯、以及「HGB 未勝過邏輯斯迴歸」的結論相當穩健；凡是需要把「螢幕」與「晚」再細分開來的結論，都對樣本與設定敏感，這也是第 6 章詮釋時有所保留的部分。
